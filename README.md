# Web Application Frameworks — Lab & Projects Portfolio

This repository contains all lab assignments, hands-on projects, and practical coursework completed for the **Web Application Frameworks** course. It serves as a central hub showcasing full-stack/frontend web applications, UI/UX responsiveness, and modern web architectures.

* **Frontend:** HTML5, CSS3 (Flexbox, CSS Grid), JavaScript (ES6+), Responsive Web Design
* **Styling & Design:** Media Queries, Custom CSS Properties, Modern Layout Structures
* **Version Control & Deployment:** Git, GitHub, GitHub Pages
